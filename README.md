# Toolpack
The NanoSharp toolpack is a pack of different NanoSharp tools, such as: <br>
<li>ns2exe</li> <br>
<li>ns2app</li> <br>
To use any of the listed tools, follow instructions below: <br>
<br>
<strong>ns2exe:</strong>
<hr>
1. Download ns2exe.ps1 and nanosharp.exe in the same folder
2. Run `.\ns2exe.ps1 -ScriptPath <script.ns>` in Powershell
A EXE should appear in your current working directory. <Br>
<Br>
<strong>ns2app:</strong>
<hr>
1. Download ns2app.sh and install NanoSharp in `/Applications/`
2. Run `./ns2app.sh <script.sh>`
A application should appear in your current working directory. <br>
